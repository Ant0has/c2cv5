# Шерегеш — боевой выпуск 27.09.2026

## Опубликовано

[Трансфер в Шерегеш](https://city2city.ru/napravleniya/sheregesh) добавлен в [общий раздел направлений](https://city2city.ru/napravleniya) и летнюю подборку. В разделе теперь семь страниц мест. Добавлен один URL в sitemap: прежние адреса не удалялись и не переезжали. Локальный утверждённый образец сохранён как история дизайна.

Сохранены четыре утверждённых фона: рисованные первые экраны и фотореалистичные вторые, зима/лето. Автоматические границы — 15 сентября и 15 апреля, ручной выбор сезона — на первом экране. Зимнее оформление не утверждает, что склоны уже открыты.

Используется общий действующий конструктор, а не локальные снимки цен. Пять городов отправления: Новокузнецк, Кемерово, Новосибирск, Томск и Барнаул. Существующие четыре страницы отдельных маршрутов остаются доступными по старым URL.

Специальных отдельных полей для лыж и обратного трансфера в боевой конструктор этим выпуском не добавляли. Их число, размеры и план возвращения пока указываются в пожеланиях. Общие правила заявок, CRM, Telegram и тарифы не менялись.

## Проверки

- 82 общие автоматические проверки: прежние страницы и сезоны плюс десять новых проверок Шерегеша. Отдельно проверен формат заявки без отправки: международный телефон, буквальное время подачи, выбранные дополнительные параметры после `&`.
- 137 HTTP-проверок до переключения и 137 после публикации: новая страница, обзор, прежние направления и контрольные старые страницы, метаданные, canonical, ресурсы, четыре изображения, sitemap и ответ 404 неизвестного направления.
- После добавления Шерегеша в sitemap 5 353 URL; прирост ровно один URL. Это число адресов sitemap, а не число уникальных бизнес-маршрутов.
- Обновление страницы через используемый CRM механизм подтверждено ответом `REVALIDATED`. Привязка CRM переключена вместе с frontend на порт 3018.
- Все пять расчётов через боевой API успешны. Все четыре ссылки на старые горнолыжные маршруты — HTTP 200 с собственным canonical, без редиректа.
- В браузере проверен переход из обзора на Шерегеш, первоначальный расчёт Новокузнецк — Шерегеш, затем смена на Кемерово с сохранением универсала, трёх пассажиров, ребёнка 6 лет и двух чемоданов.
- Переключение лето/зима сохраняет параметры. Пожелание сохраняется после закрытия и повторного открытия формы.
- Просмотрены desktop 1280 px и mobile 390 px. На 320 px ширина документа 309 px, размер обоих фрагментов H1 — 32 px; на 390 px ширина документа 379 px. Горизонтального переполнения документа нет. Ошибок консоли при проверке не обнаружено.

## Найденное старое расхождение — не исправлено этим выпуском

На [маршрутной странице Кемерово — Шерегеш](https://city2city.ru/gornolyzhka/kemerovo-sheregesh) заголовок содержит **13 500 ₽**, а действующий калькулятор для пары городов возвращает **12 500 ₽ / 380 км**. Заголовок одинаков в предыдущем и новом runtime, то есть это не регрессия публикации Шерегеша.

Старый шаблон получает данные через `destinationService.getBySlug`, использует `destination.seoTitle` либо `destination.price`, а сервис кэширует ответ каталога на 86 400 секунд. Новый конструктор обращается к расчёту маршрута. Точную причину расхождения в исходных данных каталога ещё нужно проверить; одних этих наблюдений недостаточно, чтобы назвать его только ошибкой кэша. Старые цены, расстояния и SEO-поля вслепую не перезаписывались. Следующая связанная задача — синхронизировать этот старый каталог с актуальным источником после проверки его модели данных.

## Сервер и резервная копия

Перед продолжением: свободно 3 987 386 368 байт, `df` показывал 3,8 GiB и 89% заполнения. Inode заняты на 15%, доступная память около 1,3 GiB. Сборка выполнена на турецком сервере, не на production.

Перед размещением новой версии рассчитан остаток с запасом: 2 316 435 573 байта, выше установленного порога 1,5 GiB. После публикации удалены только два проверенных установочных архива этого выпуска — около 347 МБ. Они не являются единственной копией: распакованный runtime сохранён на production, сборочные архивы — на турецком сервере. Предыдущая рабочая версия и резервная копия не удалены.

После очистки свободно **2 718 220 288 байт, около 2,7 ГБ**. Запас достаточен для текущего выпуска, но небольшой; перед следующей полной сборкой/публикацией нужен новый расчёт места. Бесконечно накапливать выпуски на этом диске нельзя.
