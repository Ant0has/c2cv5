# Зафиксированный выпуск 14 сентября 2026

Это архив проверенных изменений, **не автоматически применяемая конфигурация**.

- `mezhgorod_redirects.conf` — точная опубликованная карта 4270 правил. Старый комментарий о 688 правилах внутри файла исторический; новый верхний заголовок и фактическое число строк соответствуют 4270.
- `sitemap.xml` — точный проверенный результат с 5345 URL.
- `nginx-runtime.patch` — изменение размещения frontend, общего пула ресурсов и исправление исходящего домена перенаправлений.
- `production-changes.patch` — полная точная дельта 29 файлов приложения и sitemap относительно снимков production перед соответствующими этапами. Это не патч, который следует без проверки применять к любому Git HEAD.
- `release-record.json` — контрольные суммы, состав исходных изменений и результаты приёмки.

Почему sitemap хранится отдельно: до этой работы Git уже отставал от production — 20 URL добавлены, 15 убраны ранее, даты lastmod также отличались. Полный staging `public/sitemap.xml` смешал бы эти прежние изменения с текущей задачей. Поэтому рабочий публичный файл не переписывается, а в истории сохраняются точный итог и точная дельта нашего этапа.

Код ссылок фиксируется отдельно от прежних незакоммиченных правок цен. В пересекающихся файлах Git сохраняет лишь изменение ссылок; рабочие файлы сервера остаются целиком нетронутыми.

Данные окружения, ключи, резервные копии PM2, полные приватные выгрузки и архивы сборок сюда не включены. Сведения об эксплуатации и откате — в [статусе проекта](../../../docs/PROJECT_STATUS.md).
